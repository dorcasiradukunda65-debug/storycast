Deliverable 2

Low-Fidelity Structural Wireframes

Structural blueprints focusing on semantic HTML5 landmarks, reading order, accessibility affordances, and container-queried layout zones.

storycast.org/ (Wireframe)
[HEADER: <header> + Logo + <nav> + Skip-Link]
[HERO SECTION: <section> + <h1> + CTA Buttons]
[CONTAINER QUERY ZONE: Featured Story Banner]
• Small width: Stacks vertically
• ≥460px: Two-column split layout
• ≥740px: Expansive editorial banner
[FILTER CONTROLS: <fieldset> with aria-pressed pills]
[STORIES GRID: CSS Grid 1fr / 2fr / 3fr container]
[ACCESSIBILITY PILLARS: 3-column feature highlights]
[FOOTER: <footer> + Sitemap + Standards Links]
storycast.org/story/detail (Wireframe)
[HEADER + BREADCRUMB NAVIGATION]
[ARTICLE HEADER: <h1> + Meta + Author Info]
[ACCESSIBLE VIDEO: <video> + <track captions>]
[CUSTOM CONTROLS: Play, -10s, +10s, Speed, CC]
[FIGCAPTION: Audio & Visual Descriptions]
[LOSSLESS AUDIO: <audio> with -16 LUFS Master]
[ASIDE: Interactive Synchronized Transcript]
• Live search input with aria-live
• Time-coded seek triggers ([00:03], etc.)
• Downloadable .TXT and .VTT links
[RELATED STORIES: Container-queried cards]
[FOOTER: Navigation & WCAG AA Badge]
storycast.org/about (Wireframe)
[HEADER: <header> with active aria-current="page"]
[MISSION STATEMENT: <section> + <figure> + <figcaption>]
[3 PILLARS: Acoustic Engineering, Transcripts, Semantic Web]
[WCAG 2.1 AA CONFORMANCE AUDIT TABLE]
• Perceivable (1.1.1, 1.2.2, 1.4.3)
• Operable (2.1.1, 2.4.1, 2.4.7)
• Understandable (3.1.1, 3.2.3, 3.3.2)
• Robust (4.1.2, 4.1.3)
[KEYBOARD SHORTCUTS REFERENCE CHEATSHEET]
[ACCESSIBILITY FEEDBACK FORM <form>]
[FOOTER: Copyright & Legal Policies]
